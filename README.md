# OCB Inside – Android-App

Die Android-App für **OCB Inside**, die Clan-Verwaltung von OthersCantBeat.
Hier gibt es nur die fertigen Downloads; der Quellcode liegt in einem privaten Repo.

## Installieren

1. Auf dem Handy diesen Link öffnen:
   **[ocb-inside.apk herunterladen](https://github.com/OthersCantBeat/inside-android/releases/latest/download/ocb-inside.apk)**
2. Die heruntergeladene Datei öffnen.
3. Beim ersten Mal fragt Android, ob dein Browser (bzw. „Dateien“) Apps
   installieren darf: **Einstellungen → Diese Quelle zulassen**, dann zurück
   und **Installieren**.
4. Die App öffnen und mit deinem Inside-Konto anmelden.

Voraussetzung: Android 8.0 oder neuer, ein echtes Handy (keine Emulatoren).

## Updates

Neue Versionen stehen unter [Releases](https://github.com/OthersCantBeat/inside-android/releases).
Einfach die neue `ocb-inside.apk` laden und drüber installieren – die
Anmeldung bleibt erhalten.

## Ist die Datei echt?

Jedes Release nennt den SHA-256-Fingerabdruck des Signaturzertifikats. Android
installiert ein Update nur, wenn es mit demselben Schlüssel signiert ist wie die
installierte App. Und der Server von OCB Inside lässt nur die echte App herein.

## Probleme

Fehler in der App direkt über **Konto → Bug melden** schicken oder im Discord
bei der Leitung melden.
